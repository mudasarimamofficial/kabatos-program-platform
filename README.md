# Kabatos Program Platform

## Phase B Frontend Reference

Initial brand: **COMPREX**

Built with Next.js App Router, TypeScript, and Tailwind CSS. The backend is **not yet connected**. This phase uses centralized mock data and ephemeral frontend state only.

## Commands

```bash
pnpm install
pnpm dev
pnpm typecheck
pnpm test
pnpm test:unit
pnpm test:e2e
pnpm build
```

`pnpm test:e2e` is currently an explicit blocked check until Playwright is provisioned. Phase C will replace mock data, prototype checkout, and prototype admin access with production services.
